Delete your Spellbun account

KingSPi · Spellbun  ·  Last updated: 18 September 2026

This page is the web resource for requesting deletion of a Spellbun account and the data we store with it. You do not need to reinstall the game to make a request.

If you still have the game

The fastest path is in the app:

  1. Open Spellbun.
  2. Go to Settings.
  3. Tap Delete account & data and confirm.

That removes your cloud save, matching Arcade records, and local progress, then starts a new anonymous session. Store purchases (for example Remove ads and coin packs) stay with Google Play or the App Store. Use Restore purchases if you play again on the same store account.

If you uninstalled Spellbun (or cannot open Settings)

Request deletion here. You do not have to download the game again.

Open a deletion request

Submit a GitHub issue titled “Spellbun account deletion request.” We use it only to find and delete your account.

Include:

  • the Google (or Apple) account email you used with Link account, if you linked;
  • your Arcade player name, if you set one;
  • anything else that helps us identify the save (for example an approximate last play date).

Do not post passwords, access tokens, or purchase receipts. If you never linked an account, say so. Anonymous progress is often already gone after uninstall; we will still delete any matching cloud row we can identify.

We aim to complete identified requests promptly. We may keep limited records where the law requires it (for example a log that we processed a deletion). Analytics and crash reports already sent to GameAnalytics or Sentry follow those services’ retention. AdMob and the stores keep their own records under their policies.
